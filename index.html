BACKGROUND

About Me

I build software because I enjoy creating tools that are fast, useful, and respect the person using them.

A lot of the modern web relies on heavy cloud servers and recurring subscriptions for tasks that modern browsers and devices can handle locally. My focus is leveraging client-side compute, WebAssembly, and browser storage to build utilities that run fast at near-zero server cost.

I live and work in West Jakarta, Indonesia. When I'm not building web apps, I publish technical deep-dives on AIMedium and explore open-source tooling.
